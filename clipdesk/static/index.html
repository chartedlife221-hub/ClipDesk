Keyboard shortcuts

Shortcuts are off while you're typing in a field. Press Esc to leave a field.

SpacePlay / pause source
PReplay just the selection
I / OSet start / end at the playhead
← →Seek 1 s (Shift: 5 s)
[ ]Nudge start / end −/+0.2 s (Shift: end)
GGo to a timestamp
/Describe a moment to find
J / KNext / previous clip
AApprove clip
RReject clip
U or Ctrl/⌘ ZUndo last change on this clip
VRender preview with the export pipeline
EExport MP4 (approves first if needed)
