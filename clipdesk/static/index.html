Keyboard shortcuts

They pause while you type in a field. Press Esc to leave the field.

SpacePlay or pause the source
PReplay the selection
I OSet start or end at the playhead
← →Seek 1 second (Shift for 5)
[ ]Nudge the start 0.2 seconds
{ }Nudge the end 0.2 seconds
GGo to a timestamp
/Describe a moment to find
J KNext or previous clip
A RApprove or reject
U or Ctrl ZUndo the last change
VRender a preview file
EExport the MP4
